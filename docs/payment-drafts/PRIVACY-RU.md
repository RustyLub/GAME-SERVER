## 2. Какие данные могут обрабатываться

Для Steam-входа и работы личного кабинета:
- SteamID64;
- публичное имя и URL аватара Steam, если они получены из публичного профиля;
- внутренний идентификатор пользователя Firebase;
- технические сведения о сессии, дата и время входа, одноразовые коды обмена (в базе хранится их хеш).

Для оформления и исполнения платного заказа после отдельного запуска:
- SteamID64 и внутренний идентификатор пользователя;
- идентификатор заказа и транзакции;
- сумма, валюта, состояние и даты платежа;
- сведения о предоставлении и сроке действия цифровой услуги;
- переписка и документы, которые пользователь добровольно направил в поддержку.

Полные данные банковской карты и платёжные пароли сайт Rusty.Lub получать и хранить не должен. Их обработка выполняется на стороне выбранного платёжного провайдера по его правилам.

## 3. Цели обработки

Данные могут использоваться только для:
1. подтверждения входа через Steam и защиты аккаунта;
2. создания и обслуживания профиля Rusty.Lub;
3. оформления заказа и проверки факта оплаты;
4. предоставления, продления и прекращения цифровой услуги;
5. предотвращения повторных, ошибочных и мошеннических операций;
6. рассмотрения обращений, возвратов и обязательной бухгалтерской/налоговой отчётности.

## 5. Передача данных третьим лицам

Для работы сервиса предполагается использование:
- Steam — для проверки OpenID-входа и получения публичных данных профиля;
- Firebase / Google Cloud — для авторизации и хранения профиля;
- выбранного платёжного провайдера — только после отдельного утверждения платёжной интеграции;
- хостинга сайта и серверной инфраструктуры — для доставки страниц и обработки запросов.

До публикации необходимо указать юридические наименования провайдеров, ссылки на их политики, фактические страны обработки и возможные трансграничные передачи. Не следует передавать провайдерам больше данных, чем нужно для соответствующей операции.

## 6. Хранение и защита

Секреты, ключи API, пароли RCON, ключи Firebase Admin и платёжные секреты должны храниться только в серверном Secret Manager / серверных переменных. Они не должны попадать в JavaScript-сборку, публичный репозиторий, URL, логи или браузер.

Доступ к профилям и заказам ограничивается принципом минимальных привилегий. Пользователь может читать только собственный профиль. Изменение SteamID64, статуса оплаты и срока услуги выполняется только доверенным сервером.
